# Security Policy

## Reporting a Vulnerability

Email intel@gratiacore.com with details. Please do not open a public issue
for security problems.

We aim to respond within 48 hours and ship a fix within 7 days for critical
issues.

## Scope

In scope:
- Extension code in this repository
- Token generation and vault handling
- Content script injection and sandboxing

Out of scope:
- The gcprotect.tech dashboard (separate codebase)
- Supabase or Stripe infrastructure
- Issues requiring physical access to a user's machine
